# 원스텝 앱 · 대표님 사용 안내

대표님이 쓰실 기능만 모았어요. 인력(회원)이 쓰는 화면은 [인력 사용 설명서](./guide-member.md)에 따로 정리했어요.
써 보시면서 불편한 점이나 원하는 기능은 [피드백 질문지](./feedback-form.md)에, 정해 주셔야 할 것은 [결정 필요 사항](./decisions.md)에 적어 주세요.

---

## 1. 들어가기
| 항목 | 내용 |
|---|---|
| 주소 | (배포 후 개발자가 알려 드려요. 예: `https://onestep-xxxx.netlify.app`) |
| 로그인 | 대표 계정으로 등록한 **카카오** 또는 **Google** 계정 |
| 화면 | PC에서 쓰기 좋게 만들었어요. 휴대폰에서도 열려요 |

로그인하면 바로 **대표 화면**이 열려요. 왼쪽(휴대폰은 위쪽)에 메뉴가 있어요.

| 메뉴 | 하는 일 |
|---|---|
| 일정 | 일정 등록·공개, 신청자 선발, 출석, 계약서, 정산 (가장 많이 쓰는 곳) |
| 가입 승인 | 초대 링크로 가입 신청한 사람을 승인·거절 |
| 회원 | 회원 목록, 등급·활동 제한, 메모, 정산 정보 |
| 초대 링크 | 가입용 링크 만들기 |
| 정산 | 지급일별 지급 처리, 이체 파일 받기 |
| 단가표 | 자주 쓰는 단가 저장, 보수 계산 규칙 |
| 계약서 양식 | 계약서 문구 고치기 |
| 설정 | 세금 방식, 회사 정보, 계약서의 주민번호 표시 |

> 체험용 화면에는 개발자가 **시험용 회원과 샘플 일정**을 미리 넣어 둬요. 회원이 하는 일(신청, 서명)도 미리 해 두니, 대표님은 대표 기능만 눌러 보시면 돼요. 실제 회원 정보는 아직 넣지 않아요.

---

## 2. 처음 한 번 할 일: 설정
**설정** 메뉴에서 세 가지를 정해요. 언제든 바꿀 수 있고, 바꿀 때마다 기록이 남아요.

1. **세금 (원천징수)**: 기타소득 8.8% / 사업소득 3.3% / 원천징수 없음 / 아직 정하지 않음
   - 세무사와 확인하기 전이면 "아직 정하지 않음"으로 두세요. 이때 정산은 **"확정 전"**으로만 저장되고, 지급 완료 처리는 할 수 없어요. 실수로 잘못된 금액이 나가지 않게 막아 둔 거예요.
   - 과세최저한·소액부징수 적용, 교통비·지방비를 세금 계산에 넣을지도 여기서 골라요.
2. **회사 정보**: 회사 이름, 대표자, 사업자등록번호, 주소, 연락처. 계약서의 "회사(갑)" 칸에 들어가요.
3. **계약서의 주민등록번호**: 뒷자리 가리기(권장) / 전체 표시

## 3. 회원 받기
### 초대 링크 만들기 → 보내기
1. **초대 링크** 메뉴 → 사용 기간을 고르고 **링크 만들기**
2. 만든 링크를 복사해 카카오톡 등으로 인력에게 보내요.
3. 링크를 받은 사람만 가입 신청을 할 수 있어요. 필요 없어진 링크는 끌 수 있어요.

### 가입 승인
1. **가입 승인** 메뉴에 신청서가 쌓여요 (메뉴 옆 숫자 = 기다리는 사람 수).
2. 이름, 휴대폰, 경력, 추천인을 보고 **등급(핵심·일반)**을 골라 **승인**하거나 거절해요.

### 회원 관리
**회원** 메뉴 → 이름이나 번호로 찾기 → 회원을 누르면 상세 화면이 열려요.
- **등급 바꾸기** (핵심 ↔ 일반), **활동 제한·해제** (사유 필수)
- **관리자 기록**: 메모, 칭찬, 주의, 노쇼·지각 (회원에게는 안 보여요). 출석에서 노쇼·지각을 고르면 자동으로 기록돼요.
- **기본 시급**: 경력자처럼 기본보다 높게 줄 사람만 적어요.
- **정산 정보**: 주민번호·계좌가 가려져서 보여요. **원문 보기**를 누르면 전체가 보이고, 누를 때마다 기록이 남아요.

---

## 4. 단가표 정리하기
**단가표** 메뉴에서 자주 쓰는 보수 조건을 저장해 두면, 일정을 만들 때 버튼 한 번으로 불러와요.
- 처음에는 "세팅 (기본)" 시급 11,000원·최소 4시간, "진행 (기본)" 시급 11,000원이 들어 있어요.
- 한 줄마다 **★세팅일 기본 / ★진행일 기본**을 정할 수 있어요. 일정에 날짜를 추가하면 이 단가가 자동으로 들어가요.
- 아래 **공통 계산 규칙**에서 초과 근무 배율, 계산 단위, 기본 시급을 정하고, **계산해 보기**로 금액을 미리 확인할 수 있어요.

## 5. 일정 운영 (가장 많이 쓰는 흐름)
**일정** 메뉴 → **새 일정**

### ① 일정 만들기
- 종류(필기시험·면접·행사), 제목, 장소, 고객사(대표님만 보임), 안내사항, 확정자 톡방 링크
- **날짜 추가**: 세팅일·진행일을 날짜마다 넣어요. 날짜마다 시간, 모집 인원, **단가 고르기**(단가표에서 한 번에)
- 교통비·지방비: 참여한 날마다 / 일정당 한 번, 지방비는 등급별 금액
- 모든 날짜 참여 필수 여부, 신청 마감, 지급 예정일 (추천 날짜가 자동으로 나와요)
- 저장하면 **임시저장** 상태예요. 아직 회원에게 안 보여요.

### ② 공개하기
일정 상세 위쪽 버튼으로 상태를 바꿔요. 바꿀 때 회원에게 알림이 가요.

`핵심 인력에게 먼저 공개` → `일반 회원에게도 공개` → `모집 마감` → `완료 처리` (언제든 **취소** 가능, 사유 필수)

### ③ 신청자·선발 탭
- 날짜별로 신청자가 보여요. 참여 횟수, 노쇼·지각 횟수, 최근 메모를 보고 골라요.
- 사람마다 **확정 / 대기 / 미선발**을 정하고, **역할**(감독관·안내 등)과 **이 사람만 다른 단가**를 적을 수 있어요.
- 전화로 섭외한 사람은 **회원 직접 넣기**로 확정자에 추가해요.
- 다 정했으면 **선발 결과 알림 보내기**. 이때 회원 화면에 결과가 보이고, 확정자는 톡방 링크를 볼 수 있어요.

### ④ 계약 탭
- **안 보낸 ○명에게 계약서 보내기**를 누르면 확정자 모두에게 계약서와 알림이 가요.
- 서명 완료 / 서명 대기 / 안 보냄 인원이 보여요. 서명 안 한 사람에게 **다시 알림**을 보낼 수 있어요.
- **보기**를 누르면 계약서가 A4 모양으로 열리고, **인쇄 · PDF로 저장**으로 PDF를 받을 수 있어요.
- 단가나 역할을 바꿨다면 **무효로 하기**(사유 필수) 후 다시 보내요. 확정을 풀거나 일정을 취소하면 계약서는 자동으로 무효가 돼요.

### ⑤ 출석 확인 탭
- 날짜마다 확정자의 **참석 / 지각 / 노쇼**를 고르고, 초과 근무 시간을 넣어요.
- 아래에 사람별 보수 합계가 바로 계산돼요 (세금 공제 전).

### ⑥ 정산 탭
- **출석 기록으로 정산 만들기**를 누르면 사람마다 근무·초과·교통비·지방비 항목과 세금, 실지급액이 계산돼요.
- **항목 보기·고치기**로 금액을 바꾸거나 항목(식비, 보너스 등)을 더할 수 있어요. 직접 고친 정산은 다시 계산해도 덮어쓰지 않아요.
- 출석을 확인하지 않은 날은 참석으로 계산하고, 화면에 알려 줘요.

## 6. 지급하기 (정산 메뉴)
지급일(15일·말일 등)마다 여러 일정의 정산을 모아서 처리해요.

1. **정산** 메뉴 → 위쪽에서 **지급일**을 고르면, 그날 줄 사람과 금액이 나와요.
2. **이체 파일 받기 (CSV)** → 엑셀로 열어 은행 대량이체 양식에 붙여 넣어요. 같은 사람이 여러 일정을 받으면 한 줄로 합쳐져 있어요.
3. 은행에서 이체를 마치면, 목록에서 사람들을 골라 **지급 완료로 바꾸기**. 회원에게 "보수가 지급되었어요" 알림이 가요.
4. 계좌 확인 등으로 미룰 사람은 **보류**(사유 필수), 나중에 **보류 풀기**.
5. **원천징수 명세 받기**: 이름, 주민번호, 세전 금액, 세금이 담긴 파일이에요. 세무사에게 줄 자료예요.

> 이체 파일과 원천징수 명세에는 계좌·주민번호 원문이 들어 있어요. 받을 때마다 기록이 남아요. 파일은 메신저로 돌리지 말고, 다 쓰면 지워 주세요.

---

## 7. 계약서 양식 고치기
**계약서 양식** 메뉴에서 문구를 고쳐요.
- `{{이름}}`, `{{행사명}}`, `{{일자}}`, `{{장소}}`, `{{역할}}`, `{{금액}}`, `{{지급예정일}}`, `{{회사명}}`, `{{대표자}}` 같은 **빈칸**은 버튼으로 넣어요. 보낼 때 실제 값으로 바뀌어요.
- 저장할 때마다 **새 버전**이 쌓여요. 이미 보낸 계약서는 보낸 때의 문구 그대로 남아요.
- 지금 들어 있는 문구는 일반적인 초안이에요. **기존 위드싸인 계약서 문구로 바꿔 주세요.**

---

## 8. 알아 두면 좋은 것
- 회원 화면에 결과가 보이는 건 **"선발 결과 알림 보내기"를 누른 뒤**예요.
- 주민번호·계좌는 암호화해서 저장해요. 대표님도 원문을 볼 때마다 기록이 남아요.
- 막히는 화면이 있으면 **화면 캡처**와 함께 개발자에게 알려 주세요.
