# 회의록

## 2026-10-26 · 1차 기획 회의

### 확인한 사실
- 원스텝: 면접·필기시험·행사 대행 운영업체에 진행요원을 파견
- 인력은 모두 프리랜서. 핵심 인력(경력 5년 이상) 40~50명, 전체 약 550명
- 인력 풀은 10년간 지인 추천(비공개 링크)으로 확장
- 현재 도구: 모집은 카카오톡 오픈톡방, 계약은 위드싸인(1인 건별), 인원 정보는 엑셀
- 확정 후 확정 인원 톡방을 열어 안내. 현장 소통도 오픈톡방
- 문제 인력은 오픈톡방에서 내보내거나 다시 부르지 않는 방식으로 관리 (기록 없음)
- 보안서약서는 고객사가 현장에서 받음
- 정산: 기타소득 8.8%로 알고 있음(대표 확인 필요), 지급일 15일 또는 말일
- 계약서에 인력이 주민번호, 계좌번호, 주소를 직접 기입

### 결정 사항
| 주제 | 결정 |
|---|---|
| 가입 | 초대 링크로 가입 신청, 대표 승인 후 가입 완료 |
| 로그인 | 카카오, 구글 로그인 |
| 공개 순서 | 핵심 인력 먼저, 이후 일반 회원 |
| 선발 | 대표가 선발 (선착순 아님) |
| 계약 | 앱 안에서 서명 |
| 정산 | 앱에서 처리. 이체까지 되면 좋음 (1차는 이체 엑셀, 2차 지급대행) |
| 현장 소통 | 오픈톡방 유지, 앱은 링크만 안내 |
| 고객사 화면 | MVP에서 제외 |
| 형태 | 웹 + 모바일 (반응형 웹앱 + PWA) |
| MVP 목적 | 사용성 검증 |
| 대표 확인 필요 항목 | 관리자 설정에서 선택 가능하게 구현 |
| 유지보수 | 개발팀 2인 (1인은 개발 초보) |

### 대표 확인 필요
1. 원천징수 세목 (기타소득 8.8% / 사업소득 3.3%), 세무사 확인 권장
2. 지급일 규칙 (행사일 기준 어느 지급일에 넣을지)
3. 성별 수집 필요 여부
4. 계약서 문구, 단가표 전달

## 2026-10-26 · 기획 문서 재검토 후속

아래는 1차 회의에서 확정된 결정이 아니라 개발 전에 확인할 사항이다.

- [ ] 비용 없이 개발·시연을 시작한다. 실제 회사 업무에 쓸 웹 호스팅은 상업적 이용 조건과 Next.js 서버 기능을 확인한 뒤 선택한다. Vercel 계정은 선택 전 필수가 아니다. (기술 스택 6장)
- [ ] 대표·세무사: 원천징수 세목, 과세최저한 적용 단위, 세액 계산 규칙과 지급일의 주말·공휴일 처리를 확인한다. 확정 전에는 실제 지급액 확정과 이체 엑셀 생성을 막는다. (PRD 4.9절)
- [ ] 시범 운영 전에 초대 대상·일정·측정 기간을 정하고, 가입률·신청률·서명률의 분모와 처리 시간 기준값을 기록한다. (PRD 9장)
- [ ] 실제 개인정보·계약서를 넣기 전에 Supabase DB와 Storage 파일 각각의 백업·복구 절차를 정하고 시험한다.
- [ ] 계약서 문구와 단가표는 대표에게 받되, 로그인·초대·승인 개발은 먼저 진행할 수 있다.
